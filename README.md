\*Still learning, still making, still wondering what if?

## About This Sketchbook

Yunmo Sketchbook is intentionally more like an open notebook than a conventional portfolio.

Its irregular ink marks, handwritten headings, playful illustrations, and loose page layouts make space for projects **and** the process of designing them.

Each project entry explores its motivation, working ideas, technical foundations, and current state — including things that are not finished yet.

The website is built with **HTML, CSS, and vanilla JavaScript**.

## Featured Projects

### 01 · Little Steps

_Every little step opens a new story._

A storybook robot adventure following Kristie, a curious little robot who learns to navigate unfamiliar worlds and keeps challenging herself.

The project explores pathfinding, reinforcement learning, player rewards, and learning through play.

**Progress:** Seasons 1 and 2 are playable. Season 3 is in design.

[GitHub Repository](https://github.com/Yunmo0121/Little-Steps) · [Play Little Steps](https://yunmo0121.github.io/Little-Steps/)

### 02 · Wonderfield

_A magazine of mathematics you can play with._

An interactive science magazine that turns mathematical phenomena into experiments readers can explore.

Issue 1 investigates synchronisation through firefly simulations, Kuramoto models, mathematical explanations, and reproducible experiments.

**Progress:** Issue 1, _Synchrony_, is published. _Flocks_ is in preparation, and _Life_ is planned.

[GitHub Repository](https://github.com/Yunmo0121/wonderfield) · [Explore Wonderfield](https://yunmo0121.github.io/wonderfield/)

### 03 · Neural Tidepool

_A laboratory for curious minds._

An interactive computational neuroscience laboratory for exploring neural models through simulation, measurement, and experimentation.

The first lab introduces leaky integrate-and-fire neurons, different stimulus waveforms, an oscilloscope, experimental notebooks, and numerical validation.

**Progress:** Lab 1, _Single Neuron_, is available. Further laboratories are planned.

[GitHub Repository](https://github.com/Yunmo0121/Neural-Tidepool) · [Open the Lab](https://yunmo0121.github.io/Neural-Tidepool/)

## Design Language

Warm paper, charcoal-like linework, irregular ink blocks, generous whitespace, and a little red-pencil emphasis.

Drawings are deliberately simple: a few lines should be enough to tell a story.

The individual project pages follow a shared visual language while keeping their own identities.

## Built With

- HTML5, CSS3, and vanilla JavaScript
- SVG illustrations and hand-drawn visual elements
- Responsive page layouts
- GitHub Pages for static hosting

No backend, API keys, or build process are required for the portfolio itself.

## Run Locally

Download or clone the repository and open `index.html` in a modern browser.

Alternatively, start a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.
